# L1000

## Preferred Benchmark Dataset: `l1000_public`

### Source And Version

- Public GEO Level-5 sources:
  - `GSE70138`
  - `GSE92742`
- Raw files used:
  - `data/drug perturbation/LINCS_public/GSE70138/GSE70138_Broad_LINCS_Level5_COMPZ_n118050x12328_2017-03-06.gctx`
  - `data/drug perturbation/LINCS_public/GSE70138/GSE70138_Broad_LINCS_sig_info_2017-03-06.txt`
  - `data/drug perturbation/LINCS_public/GSE70138/GSE70138_Broad_LINCS_cell_info_2017-04-28.txt`
  - `data/drug perturbation/LINCS_public/GSE70138/GSE70138_Broad_LINCS_gene_info_2017-03-06.txt`
  - `data/drug perturbation/LINCS_public/GSE92742/GSE92742_Broad_LINCS_Level5_COMPZ.MODZ_n473647x12328.gctx`
  - `data/drug perturbation/LINCS_public/GSE92742/GSE92742_Broad_LINCS_sig_info.txt`
  - `data/drug perturbation/LINCS_public/GSE92742/GSE92742_Broad_LINCS_cell_info.txt`
  - `data/drug perturbation/LINCS_public/GSE92742/GSE92742_Broad_LINCS_gene_info.txt`
- Provenance status: public-ready. This is the preferred L1000 dataset for the main benchmark.

### Sample Definition

- One benchmark row is one public `trt_cp` Level-5 signature.
- Prepared sample count: `312437`
- Separate matched control pool size: `21566`
- Source contributions:
  - `GSE70138`: `107404` treated rows, `6555` controls
  - `GSE92742`: `205033` treated rows, `15011` controls

### Intervention Definition

- Intervention id: `pert_id`
- Intervention family / readable name: `pert_iname`
- Intervention type: synthetic constant `small_molecule`
- Only `trt_cp` rows are admitted into the benchmark sample table.

### Context Fields

- Canonical context field: `cid`
- Native cell context preserved as `cell_id`
- Additional public cell annotations retained in metadata:
  - `base_cell_id`
  - `cell_type`
  - `primary_site`
  - `subtype`

### Baseline Availability

- Baseline mode: `matched_control_prototype`
- Pairing regime: `semi_paired`
- Control matching rule: `source_dataset + cell_id + pert_itime`
- Controls admitted into prototype construction:
  - `ctl_vehicle`
  - `ctl_untrt`

### Preprocessing Steps

- Read public `sig_info`, `cell_info`, `gene_info`, and Level-5 `gctx` directly from GEO files.
- Restrict the feature space to the 978 landmark genes.
- Build one canonical landmark order across `GSE70138` and `GSE92742`.
- Parse dose into numeric `dose_um` and time into numeric `time_h`.
- Compute matched control prototypes within exact `source_dataset + cell_id + pert_itime` buckets.
- Export:
  - `data/prepared/l1000_public/prepared_bundle.npz`
  - `data/prepared/l1000_public/samples.csv`
  - `data/prepared/l1000_public/features.npy`
  - `data/prepared/l1000_public/feature_names.json`
  - `data/prepared/l1000_public/metadata.json`
  - `data/prepared/l1000_public/field_coverage.json`
  - `data/prepared/l1000_public/source_manifest.json`

### Feature Space

- `l1000_public_level5_landmark978`
- Landmark feature count: `978`
- `features.npy` stores `delta_response`
- `prepared_bundle.npz` stores `x_baseline`, `y_response`, and `delta_response`

### Supported Protocols

- `iid_sanity`
- `cold_intervention`
- `cold_context`
- `cold_dose_time`

### Current Limitations And Risks

- One public treatment row in `GSE92742` had completely missing dose metadata and was explicitly excluded:
  - `GSE92742::T2D001_MCH58_144H:CMAP-T2DTUNICAMYCIN:-666`
- `GSE92742` cell annotation is incomplete for `SNUC4`; `362` treated rows and `16` controls keep `cell_id=SNUC4`, while missing `cell_info` annotations are filled as `unknown` and recorded in `field_coverage.json`.
- The public benchmark currently covers compound perturbations only; `trt_sh`, `trt_oe`, `trt_lig`, and related families are not mixed into this table.
- `cross_source_transfer` is still unsupported in the current split helper because the protocol implementation requires at least 3 distinct source groups, while this public benchmark has 2 accessions.
